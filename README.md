# Gates

A browser-based logic gate circuit simulator built with React, TypeScript, MUI, and Paper.js.

[Demo](https://dpasillas.github.io/gates)

## Getting Started

Install dependencies:

```sh
npm install
```

## Available Scripts

### `npm start` (or `npm run dev`)

Runs the app in development mode with [Vite](https://vitejs.dev/).\
Open [http://localhost:3000/gates/](http://localhost:3000/gates/) to view it in the browser.

The page reloads automatically when you make edits.

### `npm test`

Runs the test suite with [Vitest](https://vitest.dev/) in watch mode.\
Use `npx vitest run` for a single pass.

### `npm run typecheck`

Type-checks the project with the TypeScript compiler without emitting output.

### `npm run build`

Builds the app for production to the `build` folder.

### `npm run preview`

Serves the production build locally for inspection.

### `npm run deploy`

Builds and publishes the `build` folder to GitHub Pages.
